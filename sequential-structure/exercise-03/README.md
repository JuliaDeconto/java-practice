# Exercise 02 - Circle Area

## Objective
Read the value of the radius of a circle and display
the area of the circle with four decimal places.

## Concepts Practiced
- Input with `Scanner`
- Variable declaration
- Mathematical operations (power and multiplication)
- Use of constants (π = 3.14159)
- Output formatting with `System.out.printf`

## Technologies
- Java Language

## How to Compile

```bash
javac Main.java
java Main
