# Exercise 06 - Total Payment for Parts

## Objective
Read the code, quantity, and unit price of two different parts, 
then calculate and display the total amount to be paid.

## Concepts Practiced
- Input with `Scanner`
- Variable declaration
- Arithmetic operations (multiplication and addition)
- Output formatting with `System.out.printf`

## Technologies
- Java Language

## How to Compile

```bash
javac Main.java
java Main
