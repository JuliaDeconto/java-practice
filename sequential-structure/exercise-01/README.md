# Exercise 01 - Variables and Formatted output

## Objective
Create a program that declares and initializes variables of different data types (String, int, char, and double) and
uses them to produce a formatted output on the console, following a specific structure.

## Concepts Practiced
- Variable declaration and initialization
- Primitive and reference data types (`String`, `int`, `char`, `double`)
- String formatting and console output
- Use of formatted output (`printf`)
- Data representation and precision formatting

## Technologies
- Java Language
