# Exercise 06 - Interval Check

## Objective
Read a numeric value from the user and determine in which of the
following intervals the value belongs: [0,25], (25,50], (50,75],
or (75,100]. If the value does not belong to any of these
intervals, display the message "Out of interval".

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if / else if)
- Comparison operators
- Logical operators
- Output with System.out.println

## Technologies
- Java Language
