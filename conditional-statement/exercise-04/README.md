# Exercise 04 - Game Duration

## Objective
Read the starting hour and ending hour of a game and calculate
its duration, considering that the game may start on one day 
and finish on the next, with a minimum duration of 1 hour 
and a maximum duration of 24 hours.

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if)
- Arithmetic operations
- Logical reasoning
- Output with System.out.println

## Technologies
- Java Language
