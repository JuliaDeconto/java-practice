# Exercise 05 - Snack Bar Order

## Objective
Read the code of an item and the quantity ordered, then calculate
and display the total amount to be paid according to the snack 
bar price table.

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if)
- Arithmetic operations (multiplication)
- Output formatting with System.out.printf

## Technologies
- Java Language
