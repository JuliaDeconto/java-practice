# Exercise 01 - Negative Number Check

## Objective
Read an integer number from the user and determine whether this 
number is negative or not, displaying the result on the screen.

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if)
- Comparison operators
- Output with System.out.println

## Technologies
