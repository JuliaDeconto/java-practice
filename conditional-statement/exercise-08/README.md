# Exercise 08 - Income Tax Calculation

## Objective
Read a salary value from the user and calculate the amount of 
income tax to be paid according to predefined tax brackets, 
displaying the result with two decimal places or indicating
that the person is exempt from taxation.

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if / else if)
- Arithmetic operations
- Percentage calculations
- Output formatting
- Output with System.out.println

## Technologies
- Java Language
