# Exercise 02 - Even or Odd Number Check

## Objective
Read a integer number from the user and determine whether this 
number is even or odd, displaying the result on the screen

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if)
- Arithmetic operators (modulus %)
- Comparison operators
- Output with System.out.println

- Java Language
