# Exercise 03 - Multiples Check

## Objective
Read two integer values (A and B) from the user and determine 
whether the numbers are multiples of each other, displaying an
appropriate message on the screen.

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if)
- Arithmetic operators (modulus %)
- Logical operators
- Output with System.out.println

## Technologies
- Java Language

```bash
javac Main.java
