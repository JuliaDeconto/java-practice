# Exercise 07 - Cartesian Coordinate Quadrant

## Objective
Read two decimal values (x and y) representing the coordinates
of a point in the Cartesian plane and determine in which
quadrant the point is located. If the point is at the origin
or on one of the axes, display the corresponding message.

## Concepts Practiced
- Input with Scanner
- Variable declaration
- Conditional structure (if / else if)
- Comparison operators
- Logical operators
- Cartesian coordinate system
- Output with System.out.println

## Technologies
- Java Language
